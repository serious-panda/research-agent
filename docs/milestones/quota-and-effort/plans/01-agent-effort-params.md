# Plan 01: Agent Effort Parameters

> Source PRD: `docs/milestones/quota-and-effort/prd-quota-and-effort.md`

## Context

The agent currently uses a single global `MAX_ITERATIONS` env var and hardcodes `max_results=5` in every search call. This plan threads an `effort` parameter through the entire agent stack so the server can control search depth at request time. It also adds usage tracking so the `done` event reports actual resource consumption.

---

## What to build

### 1. `apps/agent-api/src/agent/state.py`

Extend `ResearchState` using two-class inheritance so existing required fields remain required while new fields are optional. `run_graph()` (CLI path) continues to work without modification — it simply omits the new optional fields.

```python
from typing import TypedDict


class _ResearchStateRequired(TypedDict):
    question: str
    kind: str                   # "research" | "conversational"
    queries: list[str]
    search_results: list[dict]
    kb_results: list[dict]
    reflections: list[str]
    iteration: int
    final_answer: str | None


class ResearchState(_ResearchStateRequired, total=False):
    # Effort config — set by stream_graph() from the effort parameter
    max_iterations: int       # max reflect-loop iterations
    results_per_query: int    # max documents fetched per search call
    max_initial_queries: int  # max queries generated by plan node
    # Usage tracking — accumulated by search node
    searches_done: int
    links_evaluated: int
```

Access new fields in nodes with `.get("field", default)` — e.g. `state.get("max_iterations", MAX_ITERATIONS)`.

### 2. `apps/agent-api/src/tools.py`

Add a `_kb_search` helper (mirrors the existing `_ddg_search` pattern) so the search node can call it directly with a configurable `top_k`:

```python
def _kb_search(query: str, top_k: int = 5) -> list[dict]:
    try:
        from rag.store import search_documents
        return search_documents(query, top_k=top_k)
    except Exception as exc:
        logger.warning("kb_search failed: %s", exc)
        return []
```

The `@tool` wrappers (`web_search`, `kb_search`) are **not changed** — the LLM still selects them via `bind_tools`; execution is intercepted in the search node.

### 3. `apps/agent-api/src/agent/nodes.py`

**`plan` node** — read `max_initial_queries` from state and inject the constraint into the system prompt:

```python
def plan(state: ResearchState) -> dict:
    max_q = state.get("max_initial_queries", 5)
    result: _QueryPlan = _llm().with_structured_output(_QueryPlan).invoke([
        {
            "role": "system",
            "content": (
                "You are a research planner. Given a question, produce a focused list of "
                f"web search queries. Return at most {max_q} queries — prefer fewer "
                "high-quality queries over many redundant ones."
            ),
        },
        {"role": "user", "content": state["question"]},
    ])
    logger.info("[plan] queries=%r", result.queries)
    return {"queries": result.queries}
```

**`search` node** — call `_ddg_search` and `_kb_search` directly (bypassing `@tool` wrappers) with effort-driven result counts; accumulate `searches_done` and `links_evaluated`:

```python
from tools import _ddg_search, _kb_search, SEARCH_TOOLS

def search(state: ResearchState) -> dict:
    n = state.get("results_per_query", 8)
    query, *remaining = state["queries"]
    logger.info("[search] iteration=%d query=%r results_per_query=%d", state["iteration"], query, n)

    llm = _llm().bind_tools(SEARCH_TOOLS)
    response = llm.invoke([
        SystemMessage(
            "You are a research assistant. Use the available tools to find information. "
            "Use kb_search for domain-specific questions covered by the knowledge base. "
            "Use web_search for current events or general knowledge. "
            "Call both if the query spans both."
        ),
        HumanMessage(f"Research query: {query}"),
    ])

    web_results, new_kb_results = [], []
    for tc in response.tool_calls:
        logger.info("[search] tool_call=%s args=%r", tc["name"], tc["args"])
        if tc["name"] == "web_search":
            web_results.extend(_ddg_search(tc["args"]["query"], max_results=n))
        elif tc["name"] == "kb_search":
            new_kb_results.extend(_kb_search(tc["args"]["query"], top_k=n))

    if not response.tool_calls:
        logger.warning("[search] no tool calls from LLM, falling back to web_search")
        web_results = _ddg_search(query, max_results=n)

    fetched = len(web_results) + len(new_kb_results)
    logger.info("[search] web=%d kb=%d fetched=%d remaining_queries=%d",
                len(web_results), len(new_kb_results), fetched, len(remaining))
    return {
        "queries": remaining,
        "search_results": state["search_results"] + web_results,
        "kb_results": state.get("kb_results", []) + new_kb_results,
        "searches_done": state.get("searches_done", 0) + 1,
        "links_evaluated": state.get("links_evaluated", 0) + fetched,
    }
```

All other nodes (`classify`, `answer`, `reflect`, `synthesize`, `save`) are unchanged.

### 4. `apps/agent-api/src/agent/graph.py`

**Add `EFFORT_CONFIG`** constant at module level:

```python
EFFORT_CONFIG: dict[str, dict] = {
    "low":    {"max_iterations": 1, "results_per_query": 3, "max_initial_queries": 2, "estimated_credits": 10},
    "medium": {"max_iterations": 2, "results_per_query": 5, "max_initial_queries": 3, "estimated_credits": 20},
    "high":   {"max_iterations": 4, "results_per_query": 8, "max_initial_queries": 5, "estimated_credits": 40},
}
```

**Update `_route_reflect`** to read the limit from state (falls back to the global `MAX_ITERATIONS` env var):

```python
def _route_reflect(state: ResearchState) -> str:
    max_iter = state.get("max_iterations", MAX_ITERATIONS)
    if state["queries"] and state["iteration"] < max_iter:
        return "search"
    return "synthesize"
```

**Update `stream_graph`** signature and body:

```python
async def stream_graph(question: str, thread_id: str, effort: str = "high") -> AsyncIterator[dict]:
    cfg = EFFORT_CONFIG.get(effort, EFFORT_CONFIG["high"])
    initial: ResearchState = {
        "question": question,
        "kind": "research",
        "queries": [],
        "search_results": [],
        "kb_results": [],
        "reflections": [],
        "iteration": 0,
        "final_answer": None,
        # effort-derived fields
        "max_iterations": cfg["max_iterations"],
        "results_per_query": cfg["results_per_query"],
        "max_initial_queries": cfg["max_initial_queries"],
        "searches_done": 0,
        "links_evaluated": 0,
    }

    async with AsyncPostgresSaver.from_conn_string(AGENT_POSTGRES_DSN) as checkpointer:
        await checkpointer.setup()
        graph = _build_compiled_graph(checkpointer)
        # ... streaming loop unchanged ...

    # After loop, emit done event with usage
    final = await graph.aget_state(config)
    values = final.values
    sources = [r["href"] for r in values.get("search_results", []) if r.get("href")]
    links = values.get("links_evaluated", 0)
    yield {
        "event": "done",
        "answer": values.get("final_answer", ""),
        "sources": sources,
        "thread_id": thread_id,
        "usage": {
            "searches": values.get("searches_done", 0),
            "links": links,
            "credits": links,
        },
    }
```

`run_graph()` (sync CLI path) is **not modified**.

### 5. `apps/agent-api/main.py`

Add `effort` field to `ResearchRequest` and pass it to `stream_graph`:

```python
class ResearchRequest(BaseModel):
    question: str
    thread_id: str | None = None
    effort: str = "high"   # "low" | "medium" | "high"

@app.post("/api/research")
async def research(body: ResearchRequest) -> StreamingResponse:
    thread_id = body.thread_id or str(uuid.uuid4())

    async def generate():
        try:
            async for event in stream_graph(body.question, thread_id, effort=body.effort):
                yield f"data: {json.dumps(event)}\n\n"
        except Exception as exc:
            yield f"data: {json.dumps({'event': 'error', 'message': str(exc)})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```

```bash
cd apps/agent-api && poetry run uvicorn main:app --port 8001 --reload

# Low effort: expect ≤10 links in usage
curl -N -X POST http://localhost:8001/api/research \
  -H "Content-Type: application/json" \
  -d '{"question":"What is React?","effort":"low"}'
# → done event: "usage":{"searches":N,"links":M,"credits":M} with M ≤ 10

# High effort: expect deeper search, more links
curl -N -X POST http://localhost:8001/api/research \
  -H "Content-Type: application/json" \
  -d '{"question":"What is React?","effort":"high"}'
# → usage.links significantly higher than low

# Verify reflect stops after max_iterations:
# Low effort (max_iterations=1): at most 2 "Searching" rows in node_done events
# High effort (max_iterations=4): up to 5+ searching rows
```
